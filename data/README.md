# Data

Large survey datasets (raw GNSS, imagery, orthomosaics, point clouds) are **not tracked in git**
(see `.gitignore`). Keep them in external storage and document where they live here.

Suggested layout for a real village survey:

```
data/<village-id>/<yyyy-mm-dd>/
  base/        baseNNN.ubx, antenna notes
  drone/       gnssNNN.ubx, evtNNN.csv, images/
  ppk/         pillar.pos, drone.pos, geo.txt
  odm/         orthophoto, dsm.tif, dtm.tif
  records/     scanned village map, 7/12 extracts
  baseline.seal.json
```

A small **synthetic** dataset is generated by `demo/run_demo.py` into `demo/output/`.
